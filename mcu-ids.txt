# WeAct Studio DAP Flasher - target device ids
#
# One line per device id, fields separated by '|':
#     <register address> | <value> | <vendor> | <device name> [ | <mask> ]
#
# The mask is optional and defaults to 0xFFF (ST's 12 bit DEV_ID). Nordic's
# part number is 20 bits wide (mask 0x1FFFF), Artery's code fills the whole
# register (mask the range that identifies the family). The register is
# compared as (value & mask) == (read & mask).
#
# '#' starts a comment. Addresses are probed in the order they appear here, so
# put the ones that hit most often first. The file is read on every identify:
# edit it and press Refresh in the window, no restart needed.
#
# Without this file the program falls back to a short built-in list (the parts
# that turn up most often). See docs/mcu-identification.md.
#
